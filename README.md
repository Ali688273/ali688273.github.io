# استودیو اندروید علی | Ali Android Studio

وب‌سایت رسمی معرفی برنامه‌های اندرویدی استودیو اندروید علی.

- آدرس سایت: https://ali688273.github.io/
- زبان‌ها: فارسی و انگلیسی
- میزبانی: GitHub Pages
- ساختار: وب‌سایت ایستا؛ بدون نیاز به سرور یا پایگاه داده
- فایل اصلی: `index.html`

## انتشار با GitHub Pages

در مخزن به مسیر **Settings → Pages** بروید و در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید. سپس شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.

این پروژه از GitHub Actions برای ساخت یا انتشار استفاده نمی‌کند.

## امنیت

هیچ رمز عبور، توکن، کلید خصوصی، API key یا فایل امضای اندروید نباید در این مخزن قرار بگیرد. اطلاعات محرمانه را در فایل‌های HTML، CSS، JavaScript یا تاریخچه Git ثبت نکنید.

## به‌روزرسانی

برای افزودن یا اصلاح برنامه‌ها، کارت برنامه مربوطه در `index.html` را ویرایش کنید و لینک فروشگاه را با نشانی رسمی همان برنامه جایگزین کنید.
